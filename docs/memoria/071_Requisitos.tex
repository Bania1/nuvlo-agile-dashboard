\section{Casos de uso}

Ejemplo de como se podría formatear una tabla de caso de uso

\begin{table}
    \centering
    \scalebox{0.8}{
        \begin{tabular}{ m{8em} m{33em} } 
        \textbf{Caso de uso} & 1 Ordenar Rutinas \\
        \hline
        \textbf{Actores} &  Administrador y Cliente\\
        \hline
        \textbf{Descripción} & Se selecciona el filtro y se ordena las rutinas. \\
        \hline
        \textbf{Precondición} & El usuario está logueado en el sistema.\\  
        \hline
        \textbf{Flujo principal} &
        \begin{enumerate}[noitemsep]
            \item El Caso de Uso comienza cuando el usuario selecciona la opción de ordenar rutinas.
            \item El usuario selecciona el filtro para ordenar.
            \item El sistema pide el dato para ordenar.
            \item El usuario introduce el dato.
            \item El sistema devuelve la lista ordenada.
        \end{enumerate} \\
        \hline
        \textbf{Postcondición} & Lista de rutinas ordenadas por un filtro. \\
        \hline
        \textbf{Flujo Alternativo} & 
        Cancelar: el flujo alternativo comienza en cualquier punto del flujo principal. El usuario pulsa cancelar y la operación queda cancelada sin realizar ningun cambio.\\
        \hline
        \end{tabular}
    }
    \caption{CU30:Ordenar rutinas}
    \label{table:CU30}
\end{table}
